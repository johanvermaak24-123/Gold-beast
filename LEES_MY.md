# Gold upgrade v3

1. Pak die ZIP uit en laai die inhoud op Gold-beast se hoofvlak: index.html, backend/ en .github/.
2. Vervang .github/workflows/gold-data.yml. Verwyder ou gold-pages.yml as dit nog bestaan om dubbele deployments te vermy.
3. Settings → Pages → Source: GitHub Actions.
4. Actions → Gold app — build and publish → Run workflow. Wag vir groen.
5. Maak jou bestaande Gold-beast-skakel oop en Refresh.

Die workflow probeer elke uur op minuut 17. Refresh lees die laaste gepubliseerde verslag.

Nuut: 24H/5D/20D/60D daaglikse navorsing, nie-oorvleuelende uit-steekproeftoetse teen 'n basislyn, GLD-houerbewegings, gratis nuustemamonitor, bronstatus en berekende makrokonteks sonder vaste oorskrywing.

Dit is geskeduleerde navorsing; geen lewendige Pepperstone/MT5-prysverbinding of bewese winsgewendheid nie. Nuustemas is fraseklassifikasie en word nie as 'n volledige narratieffaktor gebruik nie. Daaglikse navorsing verskaf nie M5/M15-inskrywings nie.
